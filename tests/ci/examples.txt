# Examples compiled by CI, with both arduino-cli and PlatformIO.
#
# One sketch directory per line, relative to the repository root, built with
# the board's default menu options. The sketch file is assumed to be named
# after its directory, as the Arduino IDE requires.
#
# The list is deliberately basic: each entry exercises a different part of the
# core, from GPIO and the second core to the filesystem, SPI, I2S, USB and the
# TLS stack, rather than every example of one library.
